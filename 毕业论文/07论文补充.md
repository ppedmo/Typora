- 重要的数据库设计相关图表要有

- flowchart TD
      A([开始]) --> B[老年用户填写预约信息]
      B --> C[提交服务预约申请]
      C --> D[系统校验预约信息]
      D --> E{信息是否有效}
      E -- 否 --> F[提示重新填写]
      F --> B
      E -- 是 --> G[保存预约记录]
      G --> H[生成预约状态：待确认]
      H --> I[社区工作人员查看预约列表]
      I --> J[工作人员处理预约申请]
      J --> K[系统更新预约状态]
      K --> L[老年用户查看预约结果]
      L --> M([结束])

- flowchart TD
      A([开始]) --> B[老年用户发起紧急呼叫]
      B --> C[系统接收求助请求]
      C --> D[记录报警信息]
      D --> E[生成报警状态：未处理]
      E --> F[社区工作人员查看报警记录]
      F --> G[工作人员填写处理结果]
      G --> H[系统更新报警状态：已解决]
      H --> I([结束])

- flowchart TD
      A([开始]) --> B[系统采集老人相关业务数据]
      B --> C[生成或更新风险评估结果]
      C --> D[刷新工作人员待处理回访提醒]
      D --> E[工作人员在回访中心查看重点老人信息]
      E --> F{是否需要跟进}
      F -- 否 --> G([结束])
      F -- 是 --> H[工作人员开展电话回访、上门走访或协同处置]
      H --> I[填写随访记录]
      I --> J[系统保存随访记录]
      J --> K[更新提醒状态]
      K --> L([结束])
