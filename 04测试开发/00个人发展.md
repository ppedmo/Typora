# 对照清单

## 【第一阶段：自动化测试核心（3周）】

### 第1周：环境+元素定位入门

- [ ] 搭建自动化环境（选Java/Maven/IDEA或Python/PyCharm），成功运行“Selenium打开百度”的Demo脚本（2小时）

- [ ] 学XPath基础语法（相对路径、文本定位），用浏览器开发者工具练习定位3个网页元素（如百度搜索框、按钮）（3小时）
- [ ] 学CSS选择器基础（id、class、属性定位），定位2个复杂元素（如带动态id的按钮）（2小时）
- [ ] 整理XPath/CSS常用定位公式，记到笔记里（1小时）
- [ ] 周复盘：解决本周定位失败的1个问题（如元素未加载完成）（2小时）

### 第2周：基础操作+脚本编写

- [ ] 学Selenium基础操作：点击、输入文本、清空内容，写“打开网页→输入文字→点击搜索”的简单脚本（3小时）

- [ ] 学下拉框（Select类）和弹窗（Alert）处理，写1个包含下拉选择+弹窗确认的脚本（2小时）
- [ ] 学JUnit/TestNG（或pytest）断言方法（assertEquals、assertTrue），给脚本加2个断言（2小时）
- [ ] 尝试生成简单测试报告，查看报告中“通过/失败”结果（1小时）
- [ ] 周复盘：优化脚本，解决“元素点击失败”“断言不生效”等问题（2小时）

### 第3周：自动化用例+稳定性优化

- [ ] 选1个实习可能接触的功能（如登录模块），用等价类法设计5条适合自动化的用例（2小时）

- [ ] 把5条用例转化为自动化脚本（每条包含定位+操作+断言）（4小时）
- [ ] 学“显式等待”（WebDriverWait），解决脚本中“元素未加载”的超时问题（2小时）
- [ ] 完整跑一遍脚本，确保5条用例全部通过，记录执行时间（1小时）
- [ ] 周复盘：整理自动化核心笔记（环境配置、定位技巧、断言模板）（3小时）

## 【第二阶段：接口测试与自动化（3周）】

### 第4周：HTTP基础+Postman工具

- [x] 学HTTP核心：GET/POST区别、请求头（Cookie/Token）、响应状态码含义（2小时）

- [x] 看懂1份接口文档（含请求地址、参数、响应格式），画思维导图梳理字段（1小时）
- [x] 用Postman测2个GET接口，设置请求参数并加断言（校验状态码+响应字段）（2小时）
- [x] 用Postman测2个POST接口（带JSON参数），加3个以上断言（2小时）
- [x] 学Postman批量执行（Collection），把4个接口做成集合并运行（1小时）
- [x] 周复盘：解决“参数错误”“权限不足”的接口报错（2小时）

### 第5周：接口自动化入门

- [ ] 选工具（RestAssured/Requests），搭建接口自动化环境，跑通第一个“发送GET请求”的Demo（3小时）

- [ ] 用代码发送POST请求，传递JSON参数并解析响应结果（3小时）
- [ ] 学接口断言：校验状态码、响应体字段、业务逻辑（如“创建用户后name正确”）（2小时）
- [ ] 写1个接口自动化脚本，包含2个接口的调用和断言（2小时）
- [ ] 周复盘：解决“请求格式错误”“响应解析失败”等代码问题（2小时）

### 第6周：接口关联+参数化

- [x] 学接口关联：用第一个接口的响应结果（如token）作为第二个接口的请求参数（3小时）
- [x] 写1个包含3个接口串联的脚本（如“登录→获取用户信息→退出”）（3小时）
- [ ] 学参数化：用Excel/JSON存3组测试数据，让脚本批量跑不同参数（2小时）--数据
- [ ] 优化脚本：添加注释、异常处理（try-catch），确保报错时能输出原因（2小时）
- [ ] 周复盘：整理接口自动化模板（请求模板、断言模板、参数化方法）（2小时）

## 【第三阶段：效率工具与开发基础（4周）】

### 第7-8周：SQL进阶

- [ ] 学多表JOIN（内连接、左连接），写2条多表查询语句（如“查订单表+用户表的用户名和订单号”）（4小时）
- [ ] 学子查询，写1条“用子查询筛选条件”的语句（如“查订单金额大于平均值的订单”）（3小时）
- [ ] 学聚合函数（count/sum/group by），写2条统计类查询（如“按日期统计每天的订单数量”）（3小时）
- [ ] 学索引基础：知道“哪些字段适合加索引”“如何用explain分析慢查询”（2小时）
- [ ] 周复盘：整理SQL常用语句模板（多表查询、统计、子查询）（2小时）

### 第9周：Git必备操作

- [x] 学Git基础：安装Git，配置用户名/邮箱，初始化仓库（1小时）

- [ ] 练核心命令：clone远程仓库、创建分支（git branch）、提交代码（git commit）、推送（git push）（3小时）
- [ ] 学拉取最新代码（git pull）、解决简单冲突（手动编辑冲突文件）（2小时）
- [ ] 用Git管理自己的自动化/接口脚本，完成1次“拉代码→改脚本→提交→推送”全流程（2小时）
- [ ] 周复盘：整理Git命令清单，贴到桌面方便查阅（1小时）

### 第10周：语言补漏+提效思维

- [ ] 补编程语言基础（选你用的语言）：学集合/列表操作、循环逻辑、简单异常处理（try-catch）（3小时）

- [ ] 看懂1份同事的测试脚本，标注出关键逻辑（如定位、断言、参数传递）（2小时）

- [ ] 尝试修改脚本参数或补充1个简单功能（如给脚本加日志输出）（2小时）

- [ ] 想1个实习提效场景（如“批量生成测试数据”“自动对比接口响应差异”），写1个简单解决方案（2小时）

- [ ] 总复盘：整理所有核心笔记，分类存档（自动化、接口、SQL、Git）（3小时）
